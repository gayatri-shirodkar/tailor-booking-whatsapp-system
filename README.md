# ✂️ Gayatri Tailors - Website

A modern and responsive tailor service website designed for small businesses. This project allows customers to browse tailoring services, add items to a cart, and place orders directly via WhatsApp without requiring any backend.

---

## 🚀 Features

- 👗 Browse tailoring services (Blouses, Kurtis, Repairs)
- 🛒 Add to cart functionality
- 💰 Dynamic price calculation
- 📦 Checkout system
- 📱 WhatsApp integration for order placement
- 🎨 Responsive and attractive UI design
- ⚡ Smooth scrolling and animations

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

## 📦 How It Works

1. User selects services and adds them to the cart  
2. Fills checkout details (Name, Address, Delivery, Payment)  
3. Clicks **"Place Order"**  
4. WhatsApp opens with a pre-filled order message  
5. User sends the message  
6. ✅ Tailor receives order instantly  

---

## 📱 WhatsApp Integration

Orders are sent directly to the business owner via WhatsApp using a pre-filled message format.

Example message:
New Order - Gayatri Tailors

Name: Customer Name
Address: Customer Address
Delivery: Express
Payment: UPI

Items:
Normal Blouse - ₹500
Kurti Set - ₹1200

Total: ₹1700
